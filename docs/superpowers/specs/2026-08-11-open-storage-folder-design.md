# 打开本地存储文件夹设计

## 目标

在“设置 → 工具 → 存储空间”面板中，在现有“刷新”按钮前增加“打开本地文件夹”按钮，让用户直接使用系统文件管理器查看应用当前数据目录。

## 方案

新增一个 Tauri 命令 `settings_open_storage_folder`。命令从共享 `Storage` 实例读取真实 `data_dir`，不接受前端传入的路径，然后按操作系统调用默认文件管理器：macOS 使用 `open`，Windows 使用 `explorer`，Linux/其他 Unix 使用 `xdg-open`。

前端在 `src/lib/api.ts` 暴露 `openStorageFolder`，由 `App` 处理异步调用及全局状态错误；`SettingsTab` 通过回调触发操作，并在存储目录尚未通过刷新获得时禁用按钮。错误显示在存储空间面板中，沿用当前错误提示样式。

## 交互与文案

- 按钮顺序：打开本地文件夹、刷新。
- 刷新进行中时，刷新按钮继续显示现有“统计中...”状态；打开按钮不受刷新状态影响，但没有已知目录时保持禁用。
- 新增中英文文案：打开本地文件夹，以及打开失败的错误详情。

## 验证

- `npm run build`
- `cargo test --manifest-path src-tauri/Cargo.toml`
- 手动进入设置 → 工具 → 存储空间，刷新后点击“打开本地文件夹”，确认系统文件管理器定位到显示的数据目录。
